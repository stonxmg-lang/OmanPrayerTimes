# 🕌 مواقيت الصلاة - سلطنة عُمان

تطبيق أندرويد لعرض مواقيت الصلاة في مدن سلطنة عُمان، بالمصدر الرسمي لوزارة الأوقاف والشؤون الدينية (mara.gov.om).

## المميزات

- **4 صفحات**: المواقيت | القرآن (قريبًا) | الأذكار (قريبًا) | الإعدادات
- عرض المواقيت الستة مع إبراز الصلاة القادمة
- عد تنازلي حي قبل الصلاة بساعة (في التطبيق وفي شريط الإشعارات)
- تنبيه صوتي قبل الصلاة: الفجر قبل 5 دقائق، باقي الصلوات قبل 10 دقائق
- تشغيل الأذان كاملًا حتى مع قفل الشاشة
- وضع الصامت التلقائي أثناء الصلاة (الفجر 45د، الظهر والعصر والعشاء 35د، المغرب 25د) مع استعادة الحالة السابقة
- منبه الفجر قبل الأذان بعدد دقائق تحدده، بعدد تكرار تحدده، بدون غفوة
- تذكيرات بالصلاة على النبي ﷺ موزعة بين الفجر والعشاء (حتى 10 يوميًا، تُستثنى أوقات الصلوات)
- كاش سنوي ذكي: يُحدَّث كل 25 يومًا، وتُحمَّل السنة الجديدة تلقائيًا في آخر 10 أيام من نوفمبر - يعمل دون إنترنت
- 86 مدينة عُمانية

## بناء الـ APK في GitHub

1. ارفع هذا المشروع إلى مستودع GitHub
2. ادخل إلى تبويب **Actions** واضغط **Run workflow**
3. بعد انتهاء البناء (~10 دقائق) حمّل الـ APK من قسم **Artifacts** باسم `OmanPrayerTimes-APK`

أو محليًا:
```bash
gradle assembleDebug
```

## الملفات الصوتية (ضعها قبل البناء)

المجلد: `app/src/main/res/raw/`

| الفئة | الأسماء | العدد |
|-------|---------|-------|
| الأذان | `adhan_fajr.ogg` ... `adhan_isha.ogg` | 5 |
| تنبيه قبل الصلاة | `alert_fajr.ogg` (قبل 5د) ... `alert_isha.ogg` (قبل 10د) | 5 |
| منبه الفجر | `alarm_01.ogg` ... `alarm_10.ogg` | حتى 10 |
| التسبيحات | `tasbih_01.ogg` ... `tasbih_10.ogg` | 10 |

- الصيغة المفضولة **OGG**، ومقبول **MP3**
- التطبيق يبني ويعمل بدونها (نغمة افتراضية احتياطية) لكن ضعها قبل النشر
- كل صيغة تسبيح مرتبطة بالملف ذي رقمها (`tasbih_03.ogg` مع الصيغة الثالثة)

## الصلاحيات المطلوبة

| الإذن | الغرض |
|-------|-------|
| الإشعارات | عرض التنبيهات والأذان |
| المنبه الدقيق | تنبيهات في وقتها تمامًا |
| عدم الإزعاج | الصامت التلقائي أثناء الصلاة |
| الموقع | اختيار المدينة تلقائيًا (اختياري) |
| الإنترنت | تحديث المواقيت من الوزارة |

## البنية التقنية

- Kotlin + Jetpack Compose (Material 3)
- Gson للكاش السنوي (نفس منطق السكربت الأصلي)
- AlarmManager + WorkManager للجدولة
- ForegroundService لتشغيل الأذان المتواصل
