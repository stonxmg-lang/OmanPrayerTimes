# 🕌 مواقيت الصلاة - سلطنة عُمان

تطبيق أندرويد لعرض مواقيت الصلاة في مدن سلطنة عُمان، بالمصدر الرسمي لوزارة الأوقاف والشؤون الدينية (mara.gov.om).

## المميزات

- مواقيت الصلاة اليومية مع إبراز الصلاة القادمة
- عد تنازلي حي قبل الصلاة في التطبيق وشريط الإشعارات
- تنبيه قبل الصلاة (إشعار + صوت): المدة قابلة للتعديل (افتراضيًا الفجر 5 دقائق والباقي 10)، ولكل صلاة تفعيل مستقل
- إدارة الصمت التلقائي أثناء الصلاة
- تذكيرات بالصلاة على النبي ﷺ
- لا يوجد تشغيل للأذان ولا منبه (أُزيلا في 1.2.0)
- كاش سنوي ذكي مع تحديث تلقائي عند الحاجة
- 86 مدينة عُمانية

## الإصدار الحالي

- الإصدار: 1.2.0
- رقم البناء: 4

## بناء الـ APK

بشكل تلقائي عبر GitHub Actions، أو محليًا:

```bash
gradle assembleDebug
```

## الملفات الصوتية

المجلد: `app/src/main/res/raw/`

- صوت التنبيه قبل الصلاة: `prealert.ogg` (هو صوت قناة الإشعار، ويمكن تغييره من إعدادات النظام)
- التسبيحات (اختياري): `tasbih_01.ogg` ... `tasbih_10.ogg` — عند غيابها تُستخدم نغمة الإشعار الافتراضية

## الصلاحيات المطلوبة

- الإشعارات
- المنبه الدقيق (لوصول التنبيه في دقيقته)
- عدم الإزعاج (للصامت التلقائي)
- الإنترنت

## البنية التقنية

- Kotlin + Jetpack Compose
- AlarmManager + WorkManager (مع منبه منتصف الليل لجدولة اليوم الجديد)
- Gson cache
